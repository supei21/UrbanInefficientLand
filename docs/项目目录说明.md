# 天枢杯项目目录说明

本项目是独立的“城市低效空间再生智能系统”，目录内不保留其他项目的前端、后端或构建产物。

| 目录 | 单一职责 |
| --- | --- |
| `backend/` | Flask 应用工厂、HTTP 适配、请求校验和工作区编排 |
| `backend/api/` | 按系统、数据、分析、政策、成果、对话拆分的 Blueprint |
| `tianshu_core/` | 再生识别、空间分析、模型推理和智能体领域能力 |
| `frontend/src/api/` | Vue 前端统一 API 与流式协议客户端 |
| `frontend/src/composables/` | 可复用的前端状态与用例逻辑 |
| `frontend/src/modules/` | 数据导入、再生分析、智能助手等业务模块 |
| `frontend/src/components/` | 无业务流程依赖的通用展示组件 |
| `config/` | 分析阈值、权重和模型配置 |
| `data/` | 可复现的演示输入与比赛政策资料 |
| `runtime/` | 运行时上传、导出与索引，不作为源码维护 |
| `tests/` | 领域与 Flask API 自动化测试 |
| `scripts/` | 环境搭建、启动和统一质量检查入口 |

依赖方向固定为：`Vue → Flask Blueprint → DemoWorkspace → tianshu_core`。领域层不依赖 Flask，Vue 组件不直接操作后端文件系统。
